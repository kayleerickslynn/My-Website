# Project Rules & Guidelines

## Live Preview & Deployment
- **Always Commit and Push Changes**: Whenever modifications are made to website files (HTML, CSS, JS, assets, etc.), automatically stage, commit with a concise descriptive commit message, and push to GitHub (`origin main`).
- The user previews all changes live on their deployed site, so pushing changes at the end of every task or edit is essential across all prompts and sessions.
- Always check `git status` after making updates and ensure the working tree is clean and up to date with the remote repository.
